AGROMET LIVE — FIRST TEST BUILD

1. This package preserves the uploaded website files, except the local .git directory (which should never be replaced).
2. Back up your existing repository. Copy the package contents into your local agrologic-site repository, replacing matching files.
3. Open index.html with VS Code Live Server. The widget should appear above Contact. It will initially say 'Awaiting first station update' because no station readings are fabricated.
4. Commit and push all new/changed files using GitHub Desktop.
5. Open GitHub > Actions > 'AgroMet Live weather observations' > Run workflow. The job downloads official XML and generates agromet/stations.json.
6. IMPORTANT: The exact live XML schema could not be verified in this build environment. If the workflow fails with 'No stations parsed', the XML parsing logic must be adapted to the actual feed before readings can be displayed. Do not treat the widget as live until the workflow succeeds and the website shows real timestamps.
7. GitHub Actions scheduled workflows can run late. The widget flags snapshots older than 35 minutes as delayed. Weather values are preliminary and may be inaccurate.
8. Browser geolocation requires HTTPS and user permission. If denied, the dropdown still works.
9. GitHub repository Actions permissions must allow writing contents, and scheduled runs must be enabled.
10. Do not use this initial version for operational irrigation decisions.
